# Reported aggregates — not regenerated experimental evidence

CSV files here were copied byte-for-byte from the earlier supplied TriTrust archive. Their labels reflect that source, not independent verification. Plots are faithful visualizations of these aggregates only. The original dataset/split/checkpoints/raw outputs are absent.

`reconstructed/` contains the earlier illustrative seed tuples. They are mathematically reconstructed, not original seed runs. They are excluded from new-run statistical analysis and must not substantiate significance.

Ablation accuracy/F1 values come from the earlier CSV; the current manuscript Table8 contains latency only (its Fig6 shows ablation recognition). This distinction is retained in the supplement.
