# Reference archive and new release

The V2I reference archive was used only as an organizational example. None of its domain-specific model weights or research results were reused as gait evidence.

| Reference feature | TriTrust counterpart |
|---|---|
| Full pipeline runs | 25 real synthetic training/evaluation runs |
| Checkpoints | 15 neural weight files and10 fitted classical estimators |
| Seed/config provenance | Manifest/checkpoint/source hashes and run configs |
| Explanation files | Five-seed eight-rule audit |
| Reviewer navigation | Evidence audit, method mapping and research gate |
| Supplemental metrics | Separate reported aggregates and executed fixture outcomes |
| Source revision | Locally committed source-only Git bundle |

The reference archive itself labels its execution as controlled-fixture validation. Its large size primarily reflects neural checkpoints. The new archive follows that transparent distinction. Archive size is not evidence that historical results have been reproduced.
